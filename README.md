# CAR OS Connect

Aplikacja na telefon do systemu **CAR OS** (launcher radia Android w aucie).

- Połączenie z CAR OS przez kod QR (radio: Ustawienia → Połączenia → CAR OS Connect)
- Gdzie zaparkowałem: telefon zapisuje miejsce, gdy rozłączy się z radiem po zgaszeniu auta; radio dosyła swoją pozycję (szyfrowane AES-GCM)
- Mapa, kompas, odległość, prowadzenie pieszo, historia miejsc

Instalacja: pobierz `CarOS-Connect-*.apk` z [Releases](../../releases/latest). Android 8.0+.
